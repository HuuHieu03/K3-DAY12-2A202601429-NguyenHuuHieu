# plans

## Mục đích
Thư mục `plans/` dùng để lưu kế hoạch thực thi cho từng phiên bản, từng thay đổi, hoặc từng nhánh công việc lớn.

## Cách sử dụng
- Mỗi kế hoạch nên mô tả rõ mục tiêu, phạm vi, công việc, kiểm thử và lưu ý cho AI Agent.
- Khi bắt đầu một thay đổi lớn, hãy tạo một file kế hoạch mới theo quy tắc đặt tên chuẩn hóa trong [../README.md](../README.md).
- Các file mới nên bám theo khung trong [TEMPLATE_plan.md](TEMPLATE_plan.md).

## Quy ước
- Nếu file là Markdown chuẩn hóa, phải có YAML Frontmatter.
- Nội dung nên rõ ràng, ngắn gọn, ưu tiên thứ tự công việc và tiêu chí hoàn thành.
