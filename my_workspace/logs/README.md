# logs

## Mục đích
Thư mục `logs/` dùng để ghi nhật ký công việc, các lỗi đã gặp, root cause, cách sửa và kết quả nghiệm thu.

## Cách sử dụng
- Ghi log theo từng phiên làm việc hoặc từng sự cố đáng chú ý.
- Mô tả rõ nguyên nhân gốc, cách khắc phục và trạng thái sau khi sửa.
- Các file mới nên bám theo khung trong [TEMPLATE_log.md](TEMPLATE_log.md).

## Quy ước
- Nếu file là Markdown chuẩn hóa, phải có YAML Frontmatter.
- Log nên đủ chi tiết để lần sau có thể truy vết nhanh mà không cần đọc lại toàn bộ cuộc trao đổi.
