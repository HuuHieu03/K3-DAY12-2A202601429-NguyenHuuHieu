# docs

## Mục đích
Thư mục `docs/` dùng để lưu các tài liệu cần thiết trong quá trình review PR, trao đổi kỹ thuật, checklist xác nhận và các ghi chú hỗ trợ ra quyết định.

## Quy ước sử dụng
- Ưu tiên tài liệu ngắn gọn, rõ mục đích, dễ đọc nhanh.
- Có thể lưu tài liệu tham chiếu, checklist review, ghi chú kiến trúc, và các note cần dùng chung.
- Nếu tài liệu là file Markdown chuẩn hóa, phải tuân theo quy tắc tên file và frontmatter đã nêu trong [../README.md](../README.md).

## Gợi ý nội dung
- PR review notes
- Technical checklist
- Decision notes
- Supporting references
- Report tổng hợp phân tích dự án và kế hoạch thực hiện bài lab
