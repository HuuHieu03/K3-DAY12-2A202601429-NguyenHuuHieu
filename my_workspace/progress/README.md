# progress

## Mục đích
Thư mục `progress/` dùng để theo dõi trạng thái công việc, checklist theo phase, điểm nghẽn và các bước tiếp theo.

## Cách sử dụng
- Cập nhật progress khi có thay đổi thực tế về trạng thái công việc.
- Ghi rõ phần trăm hoàn thành, hạng mục đã xong, hạng mục đang làm và việc còn tồn đọng.
- Các file mới nên bám theo khung trong [TEMPLATE_progress.md](TEMPLATE_progress.md).

## Quy ước
- Nếu file là Markdown chuẩn hóa, phải có YAML Frontmatter.
- Progress nên phản ánh trạng thái hiện tại, không ghi chép lan man như log.
