## 2. Theo Dõi Hạng Mục Công Việc Theo Checkpoint

### Phase 0 — Setup Môi Trường & Checkpoint 0
- [x] Tạo và chuẩn bị repository đúng tên quy chuẩn.
- [ ] Thiết lập môi trường ảo Python 3.11+ và cài đặt `requirements.txt`.
- [ ] Tạo file cấu hình `.env` cục bộ (đã bỏ qua trong Git).
- [ ] Chạy lệnh test CP0: `pytest tests/ -v -m "not docker"`.

### Phase 1 — 12-Factor Config, Health & Logging (CP1)
- [ ] Hoàn thiện `app/config.py` với cấu hình Pydantic Settings và không có default cho `agent_api_key`.
- [ ] Viết hàm log JSON một dòng trong `app/logging_utils.py`.
- [ ] Định nghĩa endpoint `/health` độc lập trong `app/main.py`.
- [ ] Chạy lệnh test CP1: `pytest tests/test_cp1.py -v`.

### Phase 2 — Docker Containerization (CP2)
- [ ] Tạo Dockerfile multi-stage (builder + runtime), tối ưu cache layers và chạy bằng user `appuser`.
- [ ] Cập nhật `.dockerignore` để tránh leak `.env`.
- [ ] Thiết lập dịch vụ trong `docker-compose.yml` (agent + redis).
- [ ] Chạy lệnh test CP2: `pytest tests/test_cp2.py -v`.

### Phase 3 — API Security (CP3)
- [ ] Triển khai `secrets.compare_digest` để auth API key trong `app/auth.py`.
- [ ] Code logic sliding window rate limiter qua Redis ZSET trong `app/rate_limiter.py`.
- [ ] Code cost guard lưu trữ và kiểm soát chi tiêu theo tháng trong `app/cost_guard.py`.
- [ ] Chạy lệnh test CP3: `pytest tests/test_cp3.py -v`.

### Phase 4 — Scaling & Reliability (CP4)
- [ ] Chuyển đổi lưu trữ session sang Redis (stateless) trong `app/store.py`.
- [ ] Code endpoint `/ready` kiểm tra trạng thái kết nối Redis trong `app/main.py`.
- [ ] Cấu hình graceful shutdown xử lý tín hiệu `SIGTERM` / `SIGINT` trong `app/lifecycle.py`.
- [ ] Chạy lệnh test CP4: `pytest tests/test_cp4.py -v`.

### Phase 5 — Cloud Deployment (CP5)
- [ ] Triển khai ứng dụng lên Railway hoặc Render.
- [ ] Cấu hình biến môi trường trên cloud dashboard.
- [ ] Điền thông tin vào `DEPLOYMENT.md` và dán ảnh chụp màn hình vào `screenshots/`.
- [ ] Chạy lệnh test CP5: `pytest tests/test_cp5.py -v`.

### Phase 6 — Finalize & Answers
- [ ] Trả lời 10 câu hỏi trong `exercises.md`.
- [ ] Chạy chấm điểm tự động toàn bộ project: `python grade.py`.
